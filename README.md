# Сватбен сайт — Мария и Георги

Едностраничен сайт-покана на React (Vite), изцяло на български език.
Направен по образец на референтния Canva сайт, но с вашите снимки.

## Стартиране

```bash
npm install     # само първия път
npm run dev     # локален преглед на http://localhost:5173
npm run build   # готов сайт в папка dist/
npm run preview # преглед на готовия сайт
```

## Къде се редактира текстът

**Всичко се пише на едно място: `src/content.js`.**
Компонентите само показват това, което е там — не се налага да се пипа
друг файл, за да се смени текст, дата, час, хотел или телефон.

Местата, които трябва да се попълнят с истинските данни, са отбелязани
с коментар `// TODO`. Търсенето на `TODO` във файла ги показва всичките.

### Какво още липсва (попълва се в `src/content.js`)

| Раздел | Какво трябва |
| --- | --- |
| `couple` | фамилията на младоженците (за подписа на писмото) |
| `wedding` | точната дата и час, ден от седмицата, адрес |
| `song` | линк към песента (Spotify / YouTube). Празен линк = секцията изчезва |
| `story` | истинската история на двойката |
| `venue` | име и адрес на мястото, линк към Google Maps, часове |
| `timeline` | програмата на деня |
| `dressCode` | ако дрескодът е различен |
| `gifts` | линк за паричен подарък (Revolut / PayPal / банкова сметка). Празен линк = бутонът изчезва |
| `stay` | имената и линковете на хотелите |
| `rsvp` | краен срок, телефони и свързването на формата (виж по-долу) |
| `faq` | отговорите за деца, придружители и транспорт |

Секциите с празен линк (`song`, `gifts`) просто не се показват — сайтът
остава издържан и без тях.

## Формата за потвърждение (RSVP) — ГОТОВА И СВЪРЗАНА

Формата изглежда като част от сайта — с неговите шрифтове и цветове —
но изпраща отговорите към Google Форма. Гостите не напускат сайта и не
виждат Google.

**Свързването е направено и проверено с истинско изпращане.**
Нищо не остава за настройване.

### Къде са отговорите

- Формата (за редакция и преглед на отговорите):
  https://docs.google.com/forms/d/1DmnB9tf_9Mzu7c8Qzq46WSIW7vt13-wJ5SbQAULgowo/edit
- Раздел **Отговори** → бутон **Свързване с Таблици** прави Google
  Таблица, в която всеки отговор е нов ред. Полезно за броене на гости.

Формата е **публикувана** и приема отговори от всеки с връзката —
гостите не влизат в Google акаунт.

### Свързаните полета

| Въпрос | Поле |
| --- | --- |
| Име и фамилия *(задължително)* | `entry.650928018` |
| Ще присъствате ли? *(задължително)* | `entry.1181005927` |
| Брой гости | `entry.387497754` |
| Хранителни предпочитания или алергии | `entry.1843218141` |
| Съобщение към нас | `entry.321085290` |

### ВАЖНО при промяна на формата

Ако някой въпрос се изтрие и добави наново, номерът му (`entry.…`) се
сменя и връзката се къса — сайтът ще показва „Благодарим ви“, но
отговорът няма да стига до таблицата. Преименуването на въпрос е
безопасно; изтриването и добавянето — не.

Двата отговора на „Ще присъствате ли?“ трябва да съвпадат **дума по
дума** с `rsvp.form.attendingOptions` в `content.js`:
`Да, ще присъствам` и `За съжаление, няма да мога`.

### Резервно копие на отговорите

Сайтът е статичен — няма сървър и браузърът не може да записва файл при
вас. Затова резервното копие е **второ, независимо място**, към което се
праща същият отговор.

Защо си струва: заявката към Google се праща с `no-cors` и отговорът ѝ не
може да се прочете. Ако Google я откаже (проверено — връща `HTTP 400`),
гостът вижда „Благодарим ви“, а отговорът се губи без следа.

Настройва се в `rsvp.backup` в `src/content.js`:

```js
backup: {
  url: 'https://api.web3forms.com/submit',
  accessKey: '…',   // от web3forms.com; за Formspree се оставя празно
  subject: 'Ново потвърждение — сватба Мария и Георги',
}
```

Двете места се пълнят паралелно и провалът на едното не спира другото.
Съобщение за грешка се показва само ако отговорът не е стигнал наникъде.
Тези услуги връщат нормален отговор с CORS, тоест сайтът наистина
проверява дали е записано — мълчаливата загуба изчезва.

Ако `url` е празно, всичко работи както преди — само Google.

### Демо режим

`rsvp.form.preview: true` показва формата, но не изпраща нищо — над нея
застава жълто предупреждение. Полезно при промени по дизайна, за да не
влизат тестови редове в таблицата.

Забележка: Google не позволява четене на отговора от чужд домейн, затова
след изпращане сайтът показва благодарност, без да чака потвърждение.
Ако браузърът няма интернет, се показва съобщение за грешка и телефоните
отдолу.

## Структура

```
public/
  assets/      плик (затворен и отворен), хероу снимка, хартиена текстура
  photos/      35 снимки, смалени за уеб (макс. 1800 px)
  photos/thumb 	по-малки версии за галерията (макс. 700 px)
src/
  content.js   ← ЦЕЛИЯТ ТЕКСТ И ДАННИ
  App.jsx      реда на секциите
  components/  по един файл на секция
  components/ui/  общи елементи (заглавие, секция, появяване при скрол)
  hooks/       заключване на скрола под плика и лайтбокса
  lib/asset.js пътища до файловете от public/
  styles/global.css  цялата стилизация + дизайн променливи най-отгоре
```

## Снимки

Оригиналите в `snimki/` са 5000–8000 px (223 MB общо) — неизползваеми в
уеб. В `public/photos` са смалени копия (11 MB), а в `public/photos/thumb`
— още по-малки за решетката на галерията. Оригиналите остават непокътнати.

За да се смени снимка в някоя секция, се подава име на файл от
`public/photos` в `content.js` (`story.photo`, `venue.photo`,
`dressCode.photo`).

За да се добавят или махнат снимки от галерията, се редактира списъкът
`photos` в `content.js` (`w`/`h` са само пропорции — 2/3 за вертикална,
3/2 за хоризонтална).

## Публикуване

`npm run build` прави папка `dist/`, която може да се качи навсякъде:
Netlify, Vercel, GitHub Pages или обикновен хостинг. Пътищата са
относителни, така че сайтът работи и от подпапка.

## Дизайн

Цветовете и шрифтовете са дефинирани като променливи най-отгоре в
`src/styles/global.css` (`:root`). Шрифтовете са Google Fonts с кирилица:

- **Cormorant Garamond** — заглавия и основен текст
- **Marck Script** — ръкописните думи
- **Montserrat** — разредените главни букви
